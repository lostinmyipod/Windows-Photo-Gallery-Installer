Bring the classic Windows Vista Photo Gallery experience to modern Windows with a guided installer, photo viewing and editing features, and restored video support.

What it does

Classic Photo Gallery

Runs the Vista-era Windows Photo Gallery interface on supported modern Windows systems.

Photo & video support

Restores photo viewing, Fix and Info features, video discovery, and legacy video playback support.

Clean setup & removal

A guided installer and uninstaller handle the compatibility work without requiring manual registry edits.

Before you install

This project does not redistribute Microsoft Windows Vista binaries. You must provide your own supported original Vista files. The installer copies and applies compatibility changes only to the files you supply.

Current builds are intended for 64-bit Windows 11. Because this is a community compatibility project, testing on a restore point or non-critical machine is recommended for early releases.

Installation

  1. Download PhotoGalleryInstaller.exe from the latest GitHub release.
  2. Prepare the supported original Windows Vista Photo Gallery files requested by the installer.
  3. Run Photo Gallery Installer and select the folder containing those files when prompted.
  4. Choose the optional components you want and complete setup.
  5. Launch Windows Photo Gallery from the installer or Start menu.

Uninstalling

Use Windows Photo Gallery in Windows Installed apps, or run PhotoGalleryUninstaller.exe from the installation directory. The uninstaller removes the program and its compatibility registrations while leaving your personal pictures and videos untouched.
